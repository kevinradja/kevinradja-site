# kevinradja-site

Site de Kevin Radja, consultant Data & BI freelance. Construit avec [Astro](https://astro.build), déployé sur Vercel.

- `npm install` puis `npm run dev` pour travailler en local
- `npm run build` génère le site statique dans `dist/`
- Pages FR à la racine, pages EN sous `/en/`
- `/portfolio/` : version vitrine sans contact (pour Fiverr, Upwork, Malt)
- `public/dashboards/` : les 8 dashboards de démonstration (données fictives)
- `public/game/` : le mini-jeu Data Jump
